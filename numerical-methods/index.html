Numerical Methods Toolkit

Bisection and ODE solvers with Matplotlib visualizations

Welcome to the Numerical Methods Toolkit! This toolkit provides a collection of numerical methods and algorithms for solving mathematical problems. Explore the various methods and learn how to implement them in your own projects.

Bisection Method

The Bisection Method is a root-finding method that repeatedly bisects an interval and then selects a subinterval in which a root must lie for further processing.

ODE Solvers

ODE solvers are algorithms for solving ordinary differential equations. This toolkit includes various methods for solving ODEs, including Euler's method and Runge-Kutta methods.

Newton-Raphson Method

The Newton-Raphson Method is an iterative root-finding algorithm that uses the derivative of a function to find its roots. It converges quickly for well-behaved functions.

Learn More

Secant Method

The Secant Method is a root-finding algorithm that uses a sequence of secant lines to approximate the root of a function. It is similar to the Newton-Raphson method but does not require the computation of derivatives.

Learn More

Trapezoidal Rule

The Trapezoidal Rule is a numerical integration method that approximates the area under a curve by dividing it into trapezoids. It is a simple and effective method for estimating definite integrals.

Learn More

Simpson's Rule

Simpson's Rule is a numerical integration method that approximates the area under a curve using parabolic segments. It provides a more accurate estimate of definite integrals compared to the Trapezoidal Rule.

Learn More

Linear Regression

Linear Regression is a statistical method for modeling the relationship between a dependent variable and one or more independent variables. It is used to predict the value of the dependent variable based on the values of the independent variables.

Learn More

LU Decomposition

LU Decomposition is a matrix factorization method that decomposes a matrix into the product of a lower triangular matrix and an upper triangular matrix. It is used to solve systems of linear equations and compute determinants.

Learn More

Gaussian Elimination

Gaussian Elimination is a method for solving systems of linear equations by transforming the coefficient matrix into row echelon form. It is a fundamental algorithm in numerical linear algebra.
